# 本轮改进（目标：压过已跑基线）

诊断：Mesh-RTS v1 的 22.19 mm 主要来自 **orbital 纯旋转**（14 条 hop≈0，均值 66 mm）。像素 UVH Kabsch 把旋转光流解释成平移。8-point 有 Essential+K，同一批只有 2.5–3.6 mm。

Consensus / swap：无 GT。`sim3_resid(8pt, MASt3R)<0.45` 且两者都与 v2 残差 `>0.80` 时，换成 jerk 更低的那条。

## 诚实口径

- 单模型主结论是 MD-VGGT-v3 **5.74**。
- 标题几何方法：Mesh-RTS v3 单路径 **10.47** 已略低于 8-point；Mesh-RTS-H 10.29 仍是系统行。
