# 参照物问题与运动分解 —— 内窥镜 Egomotion 的核心理论分析

> 本文档回答三个层层递进的问题：
> 1. 图像序列里到底能观测到什么运动？（绝对 vs 相对）
> 2. 相机绝对运动凭什么可估计？（参照物从哪来）
> 3. 光流思路能否帮我们"找到参照物"？数据集应如何设计来支撑这条研究路线？

---

## 1. 运动学事实：观测永远是相对的

设世界系 W，相机位姿 $T_{wc}(t)$，场景材料点 $X(\tau) \in \mathbb{R}^3$。
像素观测是投影 $x(t) = \pi\big(T_{cw}(t)\, X(t)\big)$。

**关键分解**——像面上观测到的位移（光流）：

$$
\Delta x \;=\; \underbrace{\pi\big(T_{cw}(t{+}1)\,X\big) - \pi\big(T_{cw}(t)\,X\big)}_{\text{相机运动分量}}
\;+\; \underbrace{\pi\big(T_{cw}(t{+}1)\,X(t{+}1)\big) - \pi\big(T_{cw}(t{+}1)\,X(t)\big)}_{\text{场景运动分量}}
$$

三个直接推论：

1. **图像只含有相对运动**。对整个场景施加任意刚体变换 $G$（$T_{wc} \to G\,T_{wc}$，$X \to G\,X$），像面观测完全不变。绝对运动 = 相对运动 + 一个被选定的世界锚点。
2. **绝对运动可估 ⇔ 存在被锚定的参照物**。"锚定"意味着：某些像素的场景运动分量已知（理想为零）。此时这些像素的观测位移全部由相机运动解释 → 解出 $T_{cw}$。
3. **内窥镜的困难是三重的**：
   - 组织非刚性形变（呼吸 0.2-0.3Hz、心跳 1-2Hz、蠕动、牵拉）→ "静态场景"假设整体失效；
   - 器械独立刚体运动 → 相对相机可大可小，混入观测；
   - 湿润高光/弱纹理/烟雾 → 匹配本身不稳定。

## 2. 参照物的层次（从强到弱）

| 层次 | 定义 | 内窥镜中的实例 | 可给出的运动 | 脆弱点 |
|---|---|---|---|---|
| **L0 全局静态场景** | 整个场景在 W 中不动 | 不存在（理想化） | 绝对 $T_{wc}$（6-DoF） | — |
| **L1 静态组织区域** | 局部组织短期内位移≈0 | 视野中不动的一段肠壁 | 绝对 $T_{wc}$ | 形变传播后失效；需要逐对帧判定 |
| **L2 准刚性局部** | 短时间窗内（0.1-1s）刚性 | 结肠袋皱襞、血管分叉等解剖结构 | 窗口内绝对 $T_{wc}$ | 时间窗长度受限 |
| **L3 刚体器械** | 器械是刚体但其自身在运动 | 抓钳、钛夹 | **相对运动** $T_{\text{cam} \leftrightarrow \text{tool}}$，非绝对 | 若误当参照物，绝对轨迹被器械运动污染 |
| **L4 显式标记物** | 人工放置的已知图案 | 棋盘格标记/钛夹 | 绝对 $T_{wc}$ + 标记物位姿 | 临床中不存在；但为标定与域内锚点提供金标准 |

**核心洞见**：egomotion 的误差不是均匀的——它由"参照物可用度"决定：
$$
\text{可辨识性} \;\propto\; \frac{\text{参照物像素的面积} \times \text{视差}}{\text{非参照运动的大小}}
$$
这解释了为什么 DyEndoVO 类方法（显式估计运动掩码、只用静态区域加权位姿残差）在动态场景下显著优于整体光度法。**一个科学的数据集必须把这个"可用度"变成可控变量并给出真值。**

## 3. 光流视角：参照物 = 可被单一 SE(3) 解释的流场子集

借鉴光流思路，参照物识别可以表述为一个**流场分解**问题：

**命题**：设帧对 $(t, t{+}1)$ 的稠密前向光流为 $F$。存在位姿 $T^\star$ 与深度 $\rho$，使得"静态材料点"的流满足
$$
F(x) = \pi\big(T^\star\, \pi^{-1}(x, \rho(x))\big) - x
$$
即：静态区域的流由**单一 SE(3) + 逐像素深度**完全解释（极线约束的稠密形式）。
不满足该解释的流 = 场景运动分量（形变组织或独立运动物体）。

由此得到三条可操作的参照物识别路线（均可用本数据集直接研究/训练）：

1. **几何路线**：RANSAC 极线一致性 / 每像素反向投影深度一致性（经典VO的隐式做法）；
2. **学习路线**：以光流（或RAFT式流特征）为输入，逐像素预测"参照物概率图"（DyEndoVO 的运动掩码思路）；
3. **物理路线**：内窥镜光源与相机同轴 → 静态表面的**明暗变化可由位姿+已 知 BRDF 解释**（NFL-Depth 的 shading 先验推广）。

**退化的不可辨识情形**（数据集必须覆盖以供鲁棒性研究）：
- 纯旋转无平移 → 无视差，尺度不可观（任何深度下流场相同）；
- 参照物像素占比过低（<10%）→ 解被非参照区域劫持；
- 均匀形变场与相机运动混淆（形变场恰似一次额外刚体运动）；
- 参照物共面且与成像平面平行 → 位姿解不唯一（平面单应歧义）。

## 4. 数据集设计响应：把"参照物"做成一等公民真值

在已建成的 EndoEgoSim 管线上新增四类 GT（本设计直接落地）：

### 4.1 逐像素运动分解掩码（成对，t→t+1）

| 标签 | 含义 | 参照物资格 |
|---|---|---|
| 0 | 背景/无效 | 否 |
| 1 | **静态参照**（场景运动 < ε） | ✅ 可用于绝对 egomotion |
| 2 | 形变组织（位移 ≥ ε） | ❌（违反极线） |
| 3 | 独立运动物体 | ❌（仅给相对运动） |

判定基于**世界系场景运动**（材料点位移 / 物体位姿变化），而非像面运动——这与"绝对运动锚定"的定义严格一致。

### 4.2 稠密前向光流 GT

对每个像素的材料点：$X(t) \to X(t{+}1)$（组织按形变场、物体按刚体位姿演化）→ 投影到 $t{+}1$ 帧得流向量；含遮挡检测（投影深度 vs 渲染深度）。存储 float16 NPY + 有效性掩码。
用途：训练/评测流分解网络、运动分割、以及"流→位姿"的端到端方法。

### 4.3 参照物可用度谱系

- 每帧导出 `reference_fraction`（静态参照像素占比）；
- 场景参数把可用度做成**连续难度的可控变量**：形变强度×空间覆盖率、运动物体数量与尺寸、（可选）参照物退化场景（纯旋转、低纹理参照区）；
- 评测协议新增：**按 reference_fraction 分桶的 ATE/RPE 曲线** → 直接量化"参照物可用度 ↔ egomotion 精度"关系（论文级实验点，真实数据无法做到——真实数据无法控制形变强度）。

### 4.4 显式标记物场景（L4）

程序化"贴壁棋盘格标记"（仿真实手术中的钛夹/标定片，亦呼应本地棋盘格标定实验）：
- 已知图案 → 无歧义对应 → 金标准参照物；
- 提供 T_wo(标记物) 真值与静态参照掩码；
- 用于：绝对运动锚点研究、标记物→组织参照的迁移标定、"有/无标记物"对照实验。

### 4.5 非刚性默认化

内窥镜现实：形变是常态而非例外。数据集默认 **85% 序列含形变**，且形变升级为三类生理模式的随机组合：
- **蠕动波**：沿管腔轴向行进的收缩环（结肠镜最典型的非刚性运动）；
- **局部搏动**：心跳频率的局灶隆起（邻近血管搏动）；
- **谐波呼吸形变**：原全域低频模式。
外加工具接触形变（器械尖端附近局部压陷）。

## 5. 绝对/相对运动真值矩阵（最终GT体系）

| 真值 | 公式 | 语义 |
|---|---|---|
| 相机绝对位姿 | $T_{wc}(t)$（世界=首帧相机系） | 绝对 egomotion（锚点=首帧） |
| 相机相对运动 | $\Delta T_{ij} = T_{wci}^{-1}T_{wcj}$ | 纯观测可恢复量 |
| 物体绝对位姿 | $T_{wo}(t)$ | 物体 egomotion |
| 物体-相机相对 | $T_{co}(t) = T_{cw}T_{wo}$ | L3 参照物可给的量 |
| 场景运动场 | $X(t) \mapsto X(t{+}1)$ | 形变+物体运动的世界系真值 |
| 参照物掩码 | 逐像素静态/形变/运动 | **参照物可用度真值** |
| 稠密光流 | $F(t{\to}t{+}1)$ | 观测层运动真值 |
| 度量深度/内参/mask/bbox | — | 几何与语义支撑 |

## 6. 评测协议升级

1. **参照物分层评测**：把测试序列按 reference_fraction 分桶（如 <20%, 20-50%, >50%），分别报告 ATE/RPE → 得到"可用度-精度"曲线；
2. **掩码条件评测**：只允许方法使用参照物掩码（GT）区域时的性能上界 vs 全图使用 → 量化运动掩码的潜在收益（DyEndoVO 式方法的上界分析）；
3. **流质量评测**：EPE（端点误差）+ 静态区域流是否精确满足极线约束；
4. **退化场景专项**：纯旋转、低参照占比、强蠕动序列上的失效模式报告。

## 7. 与本地真实数据的关系

- SCARED（离体猪组织）：形变小、无蠕动——**偏"易"端**；本仿真覆盖其外的强形变/强动态区间；
- 自采 MIS 视频+棋盘格：真实标记物参照场景——转换后作为 L4 真实对照；
- CholecSeg8k：真实在体外观（含器械）——纹理域锚定。

**结论**：仿真不是真实数据的替代，而是把"参照物可用度"与"非刚性强度"从不可控的干扰变量变成**可控的实验变量**——这正是内窥镜 egomotion 研究当下最缺的工具。
