## 1. 问题定义与研究目标

**相机 Egomotion（自运动）估计**：给定内窥镜视频序列 $\{I_t\}_{t=0}^{N-1}$，估计每帧相机的刚体运动
$T_{wc}(t) \in SE(3)$（camera-to-world，即相机在世界（组织）坐标系下的绝对位姿），或等价地估计相邻帧相对运动 $\Delta T_{ij} = T_{wci}^{-1} T_{wcj}$。

**核心矛盾**：深度学习/学习型 VO 方法需要海量带精确位姿真值的训练数据，但真实内窥镜数据：
1. 位姿真值极难获取（活体组织无法贴标记；SCARED 靠 da Vinci 机械臂 FK，C3VD 靠仿真）；
2. 序列数量稀少（SCARED 仅 ~30 个 keyframe 序列）；
3. 无法控制变量（无法在同一场景下重放不同运动、不同光照）。

**本项目目标**：构建一个**可控、可复现、海量的内窥镜 egomotion 仿真数据工厂**，用本地已有真实数据作外观/几何先验，程序化生成：
- 目标物体（组织表面/腔道 + 手术器械等刚体）；
- 相机（内窥镜光学模型）；
- 二者的绝对运动与相对运动真值（完美 GT，无标注噪声）；
- 传感器级图像退化（光照、噪声、模糊）。

用于 SOTA 方法的**训练、测试、验证**与**消融分析**（如：运动幅度/形变强度/高光强度对各类方法的影响——这是真实数据做不到的）。

## 4. 三大仿真模块详细设计

### 4.1 组织/腔道几何（环境层）

程序化生成"管腔隧道"网格（模拟结肠镜/腹腔镜视野中的腔道或组织幕）：

- **基础几何**：沿中心线（直线或缓变曲线，Catmull-Rom）扫掠的圆管，长度 400–800 mm，半径 15–40 mm（从 SCARED 场景尺度采样）；
- **皱襞/褶皱**：半径沿轴向 + 周向的带限扰动（多个频率的正弦叠加 + fBm 噪声），模拟结肠袋状皱襞；
- **分岔/盲端**（可选高级模式）：二叉分岔中心线，或末端封闭盲端（逼真"顶到组织"场景）；
- **拓扑**：三角形网格 2–6 万面，顶点带 UV（用于真实纹理映射）与法线。

**纹理**（域真实感的核心）：
1. **真实纹理迁移（主）**：从 CholecSeg8k（8080帧）/ SCARED / MIS 视频构建纹理库——随机裁剪 256×256 块 + 镜像翻转拼接成可平铺纹理；HSV 色彩抖动防泄漏（纹理源按视频 ID 划分给 train/test）。
2. **程序化纹理（辅）**：血管树（随机游走分叉线画在组织色底上）+ fBm 斑点/颗粒，用于可控消融（有/无真实纹理）。

### 4.2 目标物体（动态刚体层）

内窥镜场景中的"目标物体"= 手术器械/异物，与相机构成**相对运动**：

1. **BOP LineMod 15 个网格**（现成，毫米单位，顶点色）——一般刚体；
2. **程序化器械**：圆柱杆(shaft) + 腕关节(wrist) + 夹爪(gripper) 两叶，金属高光材质参数（高镜面、各向异性近似），可参数化尺寸——更贴近腹腔镜器械；
3. **运动模型**（每个物体独立）：
   - 插入/撤出（沿器械轴平移，含速度曲线）；
   - 操摆（绕腕关节低频摆动，模拟夹持操作）；
   - 自由 6D（平滑随机 SE(3) 样条）；
   - **物体绝对位姿 T_wo(t)** 与 **相机系下位姿 T_co(t)** 同时记录 → 相对运动真值。

### 4.3 相机与运动（egomotion 层）

- **内参**：默认对齐 SCARED（fx≈1035→缩放到 640×512 即 fx≈517.7），FOV 随机 70°–120°，主点小扰动；输出分辨率默认 640×512（可配置 320×256 / 854×480）。
- **轨迹生成器**（每序列随机组合，jerk 受限保证物理合理）：
  1. **进镜/退镜**（insertion/retraction）：沿隧道中心线前进-后退，速度梯形曲线；
  2. **环视扫查**（orbital scan）：位置基本不动，光学轴大角度旋转（俯仰/偏航摆动）——SCARED 典型动作；
  3. **自由探索**（free 6D）：SE(3) 上的 Catmull-Rom 样条通过随机路标点；
  4. **颤抖叠加**（tremor）：高频小幅 6D 扰动（幅度可调，消融用）。
- **帧间运动量控制**：平移步长 0.5–8 mm/帧、旋转 0.5°–8°/帧（覆盖 SCARED 关键帧统计 + 高难样本），保证相邻帧有足够重叠（视差基线/深度比 ≤ 0.3）。

### 4.4 组织非刚性形变（v2: 默认常态 + 生理模式）

内窥镜现实：形变是常态而非例外——数据集默认 **85% 序列含形变**，强度 0.15~1.0 连续采样。
形变模型为三类生理模式的 Dirichlet 随机组合：
- **蠕动行波**：沿管腔弧长行进的收缩环（行进速度 3-12mm/s，波宽 15-45mm）——结肠镜最典型的非刚性运动；
- **局灶搏动**：局灶高斯隆起以心跳频率（0.85-1.15×1.4Hz）起伏——邻近血管搏动；
- **谐波呼吸**：全域低频时空谐波（0.25Hz 呼吸 + 慢漂移）。
外加器械接触压陷模式（周期性按压）。

**注意**：形变只作用于组织网格（环境），器械与相机仍为刚体——相机 egomotion GT 始终良定义；
同时运动分解掩码把"哪些像素因形变而失去参照资格"逐像素标出。

## 5. 渲染器设计

**选型决策：自研 numpy+OpenCV 向量化软件光栅化器**（不依赖 pytorch3d/nvdiffrast/kaolin——三者在本机 Py3.13+Torch2.11 环境均未装且编译风险高；软件渲染对本项目规模足够，且完全可控、可复现）。

### 5.1 管线（每帧）

1. 顶点变换：世界系→相机系（T_cw）→ 齐次投影（K）→ 屏幕坐标；
2. 背面剔除 + 近平面裁剪 + 三角形 bbox 光栅化（向量化重心坐标插值，double-buffer z-buffer）；
3. 属性插值：深度（mm）、法线、UV/顶点色、实例ID；
4. **内窥镜光照**（组织真实感的灵魂）：
   - 点光源与相机光心**同轴共置**（内窥镜物理结构决定）→ 强度 ∝ 1/d²，中心亮边缘暗的固有 vignetting；
   - Lambert 漫反射 + **湿组织镜面高光**（Phong，高指数 n=20–80 随机，模拟黏液湿润反光）；
   - 器械金属：更强镜面 + 边缘发暗；
5. 纹理采样（双线性，`cv2.remap` 批量加速）；
6. **传感器仿真**：泊松散粒噪声 + 读出高斯噪声、运动模糊（按帧间运动矢量方向卷积，可开关）、伽马(γ=2.2)与曝光抖动、轻度色温漂移；
7. 输出：RGB / 深度(uint16, mm) / 实例mask / 2D bbox / (可选)前向光流（顶点级投影差分）。

### 5.2 性能预估

640×512、≤6万三角形：单核 ~10–20 帧/秒 → 8 进程并行 ~100+ 帧/秒 → **10 万帧 ≈ 20 分钟量级**；百万帧数据集（≈5000 序列×200 帧）可在数小时内完成。

## 6. 真值（GT）体系——本项目的核心产出

> v2 升级：围绕"参照物问题"（详见 `docs/02_参照物与运动分解分析.md`）新增运动分解层 GT。
> 核心思想：观测只含相对运动，绝对 egomotion 必须由参照物锚定；
> 数据集必须把"什么是参照物、有多少参照物"变成带真值的可控变量。

每个序列导出如下真值（全部由仿真直接给出，**零标注误差**）：

**位姿层（绝对/相对运动真值）**

| GT | 符号 | 格式 | 用途 |
|---|---|---|---|
| 相机绝对位姿 | $T_{wc}(t)$ | TUM格式(txt) + 4×4 txt | egomotion 训练/评测主GT |
| 相机相对运动 | $\Delta T_{ij}$ | json (帧距1/2/5) | 直接监督相对位姿网络 |
| 物体绝对位姿 | $T_{wo}(t)$ | json | 物体位姿研究 |
| 物体相机系位姿 | $T_{co}(t)$ | json | **相对运动真值** |
| 标记物位姿 | $T_{wo}^{marker}$ | json | 显式参照物（棋盘格标记, L4锚点） |

**运动分解层（参照物真值——v2新增）**

| GT | 内容 | 用途 |
|---|---|---|
| 运动分解掩码 | 帧 t→t+1 逐像素: `1静态参照`(场景运动<0.2mm) `2形变组织` `3运动物体` | 参照物识别/运动分割训练与评测 |
| 稠密前向光流 | 材料点级对应（含组织形变+物体运动+遮挡检测） | 流分解网络、流→位姿方法 |
| 参照物比例 | 逐帧静态参照像素占比 | **难度分层与可控消融** |

**支撑层**

| GT | 格式 |
|---|---|
| 度量深度图 | uint16 PNG (mm) |
| 实例分割/2D框 | PNG / json |
| 形变场参数（蠕动波速/搏动频率/谐波模态） | meta.json |
| 内参/全部仿真参数 | json（同seed完全可复现） |

**坐标系约定（全项目统一）**：
- 世界系 W = 第 0 帧相机系（序列首帧相机位于原点、光轴+Z）；
- $T_{wc}$：camera-to-world；$T_{cw}=T_{wc}^{-1}$；
- 相机系：OpenCV 惯例（+X右，+Y下，+Z前）；
- 单位：毫米（mm）、度（°）；
- 深度 = 相机系 Z 值（z-buffer 存的即度量深度）。

**防泄漏划分**：
- 序列级 train/val/test = 70/15/15；
- 纹理源按**源视频 ID** 互斥划分（CholecSeg8k 的 video01-05 → train 纹理池，video06-07 → test 纹理池等）；
- 场景几何种子、运动类型分层采样保证各 split 分布一致；
- 真实锚定：SCARED d1_key1 经格式转换器进入 `real_test/`（zero-shot 域外测试）。

**格式兼容**：
- TUM RGB-D 格式（`rgb.txt/depth.txt/groundtruth.txt`）→ 直接兼容 evo、rpg_trajectory_evaluation 等标准评测工具；
- 自定义 `meta.json` 扩展位姿格式（同时提供 4×4 逐行 txt，兼容 LumenGSLAM 的加载器）。

## 7. 评测协议（对齐 SOTA 惯例）

1. **ATE RMSE**（绝对轨迹误差）：对估计轨迹先做 SE(3) 对齐（已知尺度的单目法用 Sim(3) 对齐，双报告），再计算每帧位置误差 RMS —— SCARED leaderboard 主指标；
2. **RPE**（相对位姿误差）：帧距 Δ∈{1,5,10} 的平移(m/m或mm/mm)与旋转(°/frame)误差；
3. **实现**：Umeyama 对齐（含/不含尺度）+ evo 兼容输出；本项目自带 `endosim/eval`，同时导出 evo 可读格式；
4. **基线评测计划**（后续阶段）：DUSt3R/MASt3R（本地已有权重）、8点法+RANSAC、ORB-SLAM 类（如可装）、LumenGSLAM（本地代码）在 sim test + SCARED real test 上的横向对比。

## 8. 生成流程（端到端流水线）

```
 configs/default.yaml
        │
        ▼
 [scripts/generate_dataset.py]
        │  多进程(每worker独立seed) ×  每序列:
        ├─1 采样场景参数(seed: 隧道几何/纹理源/物体集/形变强度)

        ├─3 采样相机轨迹(N帧) + 物体轨迹 + 形变时间线

        ▼
 sim_data/{train,val,test}/seq_XXXXXX/
        │
        ▼
 [scripts/verify_gt.py]  抽样核验 + 统计报告
 [scripts/evaluate.py]   评测(ATE/RPE) + 与SOTA对比表
```
